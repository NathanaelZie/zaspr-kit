Premiers pas

Introduction

ZASPR Kit est un framework CSS utilitaire écrit entièrement en Dart. Il lit vos composants, repère les classes que vous utilisez et génère la feuille de style correspondante.

Le principe

Au lieu d'écrire des sélecteurs et des règles CSS, vous composez le style directement dans vos composants avec de petites classes : p:4 pour un padding, bg:blue pour un fond, md:cols:3 pour trois colonnes à partir de la tablette.

La CLI parcourt vos fichiers Dart, extrait ces classes et produit une feuille de style qui ne contient que ce qui est réellement utilisé. Aucun JavaScript n'est nécessaire à l'exécution et aucun outil Node.js n'intervient dans la chaîne.

Un premier exemple

Chaque classe correspond à une ou plusieurs déclarations CSS :

flex
.flex {
  display: flex;
}
ai:center 
.ai\:center {
  align-items: center;
}
gap:3 
.gap\:3 {
  gap: 0.75rem;
}
br:lg 
.br\:lg {
  border-radius: 0.5rem;
}
sh:md 
.sh\:md {
  box-shadow: 0 4px 6px -1px rgb(0 0 0 / 0.1), 0 2px 4px -2px rgb(0 0 0 / 0.1);
}

Pourquoi JX

  • Pensé pour Jaspr : les classes s'écrivent dans l'attribut classes de vos composants, sans fichier CSS à maintenir.
  • Une syntaxe propre, [variantes:]identifiant[:valeur][!], qui se lit sans ambiguïté et rejette les classes invalides.
  • Un thème tokenisé : couleurs, espacements et breakpoints se configurent dans jx.yaml.
  • Une feuille minimale, triée mobile-first, qui ne grossit qu'avec ce que vous utilisez.
  • Un moteur utilisable comme bibliothèque : ce site compile ses exemples au rendu.

Version 0.2.0

ZASPR Kit est en version 0.2.0 : la syntaxe et le catalogue d'utilitaires peuvent encore évoluer avant la version 1.0.
