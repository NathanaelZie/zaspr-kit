Getting started

Automatic builds

With jx_builder, jaspr serve and jaspr build write the stylesheet themselves.

jx_builder plugs JX into build_runner, the build system Jaspr already runs. There is no second terminal and no jx build -w to keep alive: the stylesheet is rebuilt on every save, together with your components.

Installation 

dart pub add dev:jx_builder
jaspr serve

Link the stylesheet once, in your Document: 

Document(
  head: [link(rel: 'stylesheet', href: '/jx.css')],
  body: App(),
)

Configuration

The builder reads the same jx.yaml as the CLI: content, extensions, exclude, packages, minify, reset, dark_mode and theme. output is ignored: the file is always served at /jx.css.

Note

jx.yaml is read when the build starts. To have changes picked up while jaspr serve runs, add it to the target sources in build.yaml.

Minify in release

Moving from jx build

  • Delete the web/jx.css written by the CLI: build_runner refuses to overwrite a source file.
  • Remove jx build from your scripts. jx migrate and jx init stay useful.
