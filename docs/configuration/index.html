Premiers pas

Configuration

Le fichier jx.yaml décrit les sources à analyser, la sortie et les extensions du thème.

Le fichier jx.yaml

La CLI cherche jx.yaml dans le dossier courant. Sans fichier, les valeurs par défaut s'appliquent. Un chemin différent se passe avec --config.

Options

Clé Type Défaut Rôle
content liste [lib, web] Fichiers ou dossiers à scanner.
extensions liste [dart, html] Extensions lues, sans le point.
exclude liste build, .dart_tool, .git, node_modules Noms de dossiers ignorés, ajoutés aux défauts.
output chemin build/jx.css Fichier CSS généré.
minify booléen false Minifie la sortie.
reset booléen true Inclut le preflight en tête de feuille.
dark_mode media | class media dark: suit le système, ou une classe dark posée sur un ancêtre.
theme table {} Clés extend et override.

Étendre le thème

theme.extend ajoute ou remplace des tokens sans toucher aux autres : la couleur brand ci-dessus devient disponible pour c:, bg:, bc:… à côté de la palette par défaut.

theme.override remplace une catégorie entière : seules les clés déclarées restent disponibles. Les catégories sont listées dans la page Thème.

bg:blue-700 
.bg\:blue-700 {
  background-color: #1d4ed8;
}
c:teal-300 
.c\:teal-300 {
  color: #5eead4;
}

Validation

Une clé inconnue arrête la compilation avec un message explicite, par exemple Clé inconnue dans jx.yaml : "ouput". Sous theme, seules extend et override sont acceptées.
