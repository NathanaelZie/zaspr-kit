Fondamentaux

Variantes

Les variantes appliquent une classe sous condition : à partir d'une largeur d'écran, dans un état, ou sur un pseudo-élément.

Breakpoints

JX est mobile-first : une classe sans breakpoint s'applique partout, md: à partir de 768 px, et ainsi de suite. Les règles sont triées par largeur croissante.

Variante Largeur minimale Exemple
sm: 640px sm : cols : 2
md: 768px md : cols : 2
lg: 1024px lg : cols : 2
xl: 1280px xl : cols : 2
2xl: 1536px 2xl : cols : 2
cols:1 
.cols\:1 {
  grid-template-columns: repeat(1, minmax(0, 1fr));
}
md : cols : 2 
@media (min-width: 768px) {
  .md\:cols\:2 {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
}
xl : cols : 4 
@media (min-width: 1280px) {
  .xl\:cols\:4 {
    grid-template-columns: repeat(4, minmax(0, 1fr));
  }
}

États

Les pseudo-classes s'écrivent comme des préfixes. Voici les états reconnus :

hover: focus: active: visited: disabled: checked: focus-within: focus-visible: first: last: odd: even: enabled: required: optional: valid: invalid: user-valid: user-invalid: read-only: placeholder-shown: autofill: indeterminate:
hover : bg : blue-700 
.hover\:bg\:blue-700:hover {
  background-color: #1d4ed8;
}
focus-visible : ring : 2 
.focus-visible\:ring\:2:focus-visible {
  box-shadow: 0 0 0 2px var(--jx-ring-color, currentColor);
}
disabled : o : 50 
.disabled\:o\:50:disabled {
  opacity: 0.5;
}
user-invalid : bc : red 
.user-invalid\:bc\:red:user-invalid {
  border-color: #ef4444;
}

Pseudo-éléments

Un pseudo-élément se place toujours en fin de sélecteur, quel que soit son rang dans la classe. Une classe n'en accepte qu'un seul.

Variante Sélecteur produit
placeholder: ::placeholder
file: ::file-selector-button
placeholder : c : gray 
.placeholder\:c\:gray::placeholder {
  color: #6b7280;
}
file : bg : blue 
.file\:bg\:blue::file-selector-button {
  background-color: #3b82f6;
}

Mode sombre

dark: applique une classe quand le système est en thème sombre. C'est le mode par défaut, dark_mode: media.

dark : bg : gray-900 
@media (prefers-color-scheme: dark) {
  .dark\:bg\:gray-900 {
    background-color: #111827;
  }
}
dark : c : white 
@media (prefers-color-scheme: dark) {
  .dark\:c\:white {
    color: #ffffff;
  }
}

Pour un bouton clair / sombre, passez à dark_mode: class dans jx.yaml : dark: s'active alors sous un ancêtre qui porte la classe dark, en général <html>. 

.dark .dark\:bg\:gray-900 {
  background-color: #111827;
}

Groupes et pairs

Placez la classe group sur un parent : ses descendants réagissent à son état avec group-hover:, group-focus:… Toutes les pseudo-classes acceptent ce préfixe. 

a(classes: 'group flex ai:center gap:2', [
  span(classes: 'c:gray-700 group-hover:c:blue', [.text('Lire la suite')]),
  span(classes: 'tr:transform group-hover:tx:1', [.text('→')]),
])
group-hover : c : blue 
.group:hover .group-hover\:c\:blue {
  color: #3b82f6;
}
group-focus-visible : ring : 2 
.group:focus-visible .group-focus-visible\:ring\:2 {
  box-shadow: 0 0 0 2px var(--jx-ring-color, currentColor);
}

peer fait de même entre frères : l'élément qui porte peer-* doit suivre celui qui porte peer dans le document. 

input(type: InputType.checkbox, classes: 'peer sr-only'),
span(classes: 'bg:gray-300 peer-checked:bg:teal', []),
peer-checked : bg : teal 
.peer:checked ~ .peer-checked\:bg\:teal {
  background-color: #14b8a6;
}
peer-invalid : c : red 
.peer:invalid ~ .peer-invalid\:c\:red {
  color: #ef4444;
}

Préférences et impression

Variante Condition
dark: (prefers-color-scheme: dark)
motion-safe: (prefers-reduced-motion: no-preference)
motion-reduce: (prefers-reduced-motion: reduce)
contrast-more: (prefers-contrast: more)
portrait: (orientation: portrait)
landscape: (orientation: landscape)
print: print
motion-reduce : anim : none 
@media (prefers-reduced-motion: reduce) {
  .motion-reduce\:anim\:none {
    animation: none;
  }
}
print:hidden 
@media print {
  .print\:hidden {
    display: none;
  }
}

Combiner les variantes

Les variantes se cumulent. Le breakpoint produit la requête média, les états complètent le sélecteur :

md : hover : bg : blue 
@media (min-width: 768px) {
  .md\:hover\:bg\:blue:hover {
    background-color: #3b82f6;
  }
}
lg : focus : placeholder : c : gray-300 
@media (min-width: 1024px) {
  .lg\:focus\:placeholder\:c\:gray-300:focus::placeholder {
    color: #d1d5db;
  }
}
md : dark : group-hover : c : white 
@media (min-width: 768px) and (prefers-color-scheme: dark) {
  .group:hover .md\:dark\:group-hover\:c\:white {
    color: #ffffff;
  }
}

À savoir

Une classe accepte huit variantes au plus, et une même variante ne peut pas être répétée.
