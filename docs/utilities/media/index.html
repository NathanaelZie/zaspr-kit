Media and backgrounds

Aspect ratio, image fit, background position and repeat, border style.

aspect-ratio

ar:
Class CSS properties
ar: aspect-ratio
  • Keywords: auto square video photo portrait
  • Arbitrary values: yes, in brackets
ar:auto 
.ar\:auto {
  aspect-ratio: auto;
}

object-fit

obf:
Class CSS properties
obf: object-fit
  • Keywords: contain cover fill none scale-down
  • Arbitrary values: no
obf:contain 
.obf\:contain {
  object-fit: contain;
}

object-position
