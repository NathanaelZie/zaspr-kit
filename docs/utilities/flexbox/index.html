Flexbox

Direction, alignment, order, wrapping and sizing of flex items.

align-items

ai:
Class CSS properties
ai: align-items
  • Keywords: start end center baseline stretch
  • Arbitrary values: no
ai:start 
.ai\:start {
  align-items: flex-start;
}
