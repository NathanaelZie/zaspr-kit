Utilities

Filters

Blur, brightness, contrast and saturation, on the element or on what lies behind it. Filters compose with each other.

blur

blur:
Class CSS properties
blur: --jx-blur
  • Keywords: none sm md lg xl 2xl 3xl
  • Arbitrary values: yes, in brackets
blur:none 
.blur\:none {
  --jx-blur: blur(0);
  filter: var(--jx-blur,) var(--jx-brightness,) var(--jx-contrast,) var(--jx-grayscale,) var(--jx-hue-rotate,) var(--jx-invert,) var(--jx-saturate,) var(--jx-sepia,) var(--jx-drop-shadow,);
}

@property --jx-blur {
  syntax: "*";
  inherits: false;
}
blur:50 
.blur\:50 {
  --jx-blur: blur(50px);
  filter: var(--jx-blur,) var(--jx-brightness,) var(--jx-contrast,) var(--jx-grayscale,) var(--jx-hue-rotate,) var(--jx-invert,) var(--jx-saturate,) var(--jx-sepia,) var(--jx-drop-shadow,);
}

@property --jx-blur {
  syntax: "*";
  inherits: false;
}
