Utilities

Spacing

Padding and margin, on the theme spacing scale.

padding

p: px: py: pt: pr: pb: pl:
Class CSS properties
p: padding
px: padding-left, padding-right
py: padding-top, padding-bottom
pt: padding-top
pr: padding-right
pb: padding-bottom
pl: padding-left
  • Theme tokens: spacing
  • Arbitrary values: yes, in brackets
p:8 
.p\:8 {
  padding: 2rem;
}
px:4 
.px\:4 {
  padding-left: 1rem;
  padding-right: 1rem;
}

margin

m: mx: my: mt: mr: mb: ml:
Class CSS properties
m: margin
mx: margin-left, margin-right
my: margin-top, margin-bottom
mt: margin-top
mr: margin-right
mb: margin-bottom
ml: margin-left
  • Theme tokens: spacing
  • Arbitrary values: yes, in brackets
  • Negative values: yes
m:8 
.m\:8 {
  margin: 2rem;
}
mx:4 
.mx\:4 {
  margin-left: 1rem;
  margin-right: 1rem;
}
