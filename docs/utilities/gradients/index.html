Utilities

Gradients

Gradient direction or angle, then its start, middle and end colors.

linear-gradient

grad:
Class CSS properties
grad: background-image
  • Keywords: to-t to-tr to-r to-br to-b to-bl to-l to-tl
  • Arbitrary values: yes, in brackets
grad:to-t 
.grad\:to-t {
  background-image: linear-gradient(to top, var(--jx-from, transparent), var(--jx-via,) var(--jx-to, transparent));
}
grad:50 
.grad\:50 {
  background-image: linear-gradient(50deg, var(--jx-from, transparent), var(--jx-via,) var(--jx-to, transparent));
}

gradient-stops

from: to:
Class CSS properties
from: --jx-from
to: --jx-to
  • Theme tokens: colors
  • Keywords: transparent current
  • Arbitrary values: yes, in brackets
from : transparent 
.from\:transparent {
  --jx-from: transparent;
}

@property --jx-from {
  syntax: "*";
  inherits: false;
}
from:blue 
.from\:blue {
  --jx-from: #3b82f6;
}

@property --jx-from {
  syntax: "*";
  inherits: false;
}
to:transparent 
.to\:transparent {
  --jx-to: transparent;
}

@property --jx-to {
  syntax: "*";
  inherits: false;
}
