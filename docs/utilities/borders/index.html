Utilities

Borders

Border width, color, style and radius.

border-width

bw: bwt: bwr: bwb: bwl: bwx: bwy:
Class CSS properties
bw: border-width
bwt: border-top-width
bwr: border-right-width
bwb: border-bottom-width
bwl: border-left-width
bwx: border-left-width, border-right-width
bwy: border-top-width, border-bottom-width
  • Theme tokens: border-width
  • Arbitrary values: yes, in brackets
bw:2 
.bw\:2 {
  border-width: 2px;
}
bwt:4 
.bwt\:4 {
  border-top-width: 4px;
}

border-color

bc:
Class CSS properties
bc: border-color
  • Theme tokens: colors
  • Arbitrary values: yes, in brackets
bc:blue 
.bc\:blue {
  border-color: #3b82f6;
}

border-radius

br:
Class CSS properties
br: border-radius
  • Theme tokens: border-radius
  • Arbitrary values: yes, in brackets
br:xl 
.br\:xl {
  border-radius: 0.75rem;
}
