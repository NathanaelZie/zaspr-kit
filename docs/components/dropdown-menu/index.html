Overlays

Dropdown menu

A button that reveals a list of links and actions, built on <details>. It opens without JavaScript; in the browser, Escape, a click outside and a chosen action close it.

JxDropdownMenu import 'package:jx_cli/ui.dart' New in 0.0.3

Preview

Account
  • Profile
  • Billing

Choose an action.

When to use it

  • An account menu.
  • Secondary actions of a row or a card ("Duplicate", "Delete").

Complete example

A full Jaspr component you can paste into a project.

Properties

Property Type Default Description
id String required Id of the <details> ; unique on the page.
label String required Text of the trigger button.
items List<JxMenuItem> required Links, actions and separators.
variant JxButtonVariant outline Style of the trigger, as for JxButton .
size JxButtonSize md Size of the trigger.
align JxMenuAlign start Lines the list up with the start or end of the trigger.
classes String? null Extra JX classes, appended after the component classes.

Related types

Name Role
JxMenuItem(label:, href:, onSelect:, danger:, disabled:) A link ( href ) or an action ( onSelect ).
JxMenuItem.separator() A line between groups.
JxMenuAlign start, end.

Customizing

  • Pass classes to add or override utilities: they come last, so classes: 'w:full' wins over the default width.
  • The trigger uses the button styles; the list the surface border and shadow of cards.

Responsive

  • Use align: JxMenuAlign.end near the right edge so the list stays on screen.

Accessibility

  • A disclosure: the trigger is a native <summary> announced as expanded or collapsed; Tab moves through the entries.
  • Entries are real links and buttons; a disabled link loses its href and gets aria-disabled.
  • In the browser, Escape closes the list and gives the focus back to the trigger; a click or tap outside closes it too.

Limitations

  • Rendered on the server alone, only the trigger closes it.
  • Not an ARIA menu: no arrow-key navigation between entries.
  • The list opens below the trigger and can be clipped by a parent with ov:hidden.
