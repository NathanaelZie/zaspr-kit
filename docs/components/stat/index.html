Data display

Stat

A key figure with its label, an optional change and a trend that is read aloud, not shown by color alone.

When to use it

  • Dashboard tiles (revenue, sign-ups, errors).
  • A summary row above a data table.

Complete example

A full Jaspr component you can paste into a project.

Properties

Property Type Default Description
label String required What the figure measures.
value String required The figure, already formatted.
change String? null The change, such as +12% .
trend JxTrend neutral up is green, down red: pick by meaning, not by sign.
description String? null Context under the figure, such as "vs last month".
trendLabels Map<JxTrend, String> Increase / Decrease Words read before the change.
classes String? null Extra JX classes, appended after the component classes.

Related types

Name Role
JxTrend up, down, neutral.

Customizing

  • Pass classes to add or override utilities: they come last, so classes: 'w:full' wins over the default width.
  • The tile uses the card surface; combine several in a grid.

Responsive

  • Takes the width of its column: one per row on phones in the example, three from md.

Accessibility

  • A description list (dl, dt, dd): the label is announced with its value.
  • The trend is said in words ("Increase: +12%"), the arrow is decorative: color is never the only signal.

Limitations

  • No sparkline or chart.
