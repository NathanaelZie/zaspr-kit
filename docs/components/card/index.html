Complete example

A full Jaspr component you can paste into a project.

Properties

Property Type Default Description
children List<Component> required Body of the card.
title String? null Heading of the card.
titleLevel int 3 Heading level of the title, 2 to 6, to fit the page outline.
description String? null Muted text under the title.
footer List<Component>? null Shown under a separator, aligned to the end. Usually buttons.
classes String? null Extra JX classes, appended after the component classes.

Customizing

  • Pass classes to add or override utilities: they come last, so classes: 'w:full' wins over the default width.
  • Remove the shadow with classes: 'sh:none', or tighten it with p:4.

Responsive

  • The card fills its grid cell; lay cards out with grid cols:1 md:cols:3 gap:4.

Accessibility

  • The title is a real heading (h3 by default), so cards show up in the page outline.
  • Set titleLevel so headings never skip a level.
