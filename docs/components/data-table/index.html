Data display

Data table

A table with a caption, sortable headers, numeric columns, striped rows, a sticky header and an empty state. You own the data: it reports clicks on headers.

JxDataTable import 'package:jx_cli/ui.dart' Available since 0.0.2

When to use it

  • Invoices, users, orders.
  • Any list compared column by column.

Properties

Property Type Default Description
columns List<JxColumn> required Headers, in order.
rows List<List<Component>> required One list of cells per row: text, badges, buttons…
caption String? null Title of the table, read first by screen readers.
striped bool true Alternating row background.
hover bool true Highlights the row under the pointer.
dense bool false Smaller cell padding.
stickyHeader bool false Header stays visible while the table scrolls (max height 28rem).
sortColumn int? null Index of the sorted column ( aria-sort ).
sortAscending bool true Direction of the sort.
emptyText String 'No data' Shown in a single row when rows is empty.
classes String? null Extra JX classes, appended after the component classes.

Related types

Name Role
JxColumn(label, numeric: false, sortable: false) A column: numeric aligns right with tabular digits.

Events

Callback Type Fires when
onSort ValueChanged<int>? A sortable header is clicked; gives the column index. Without it, headers are plain text.

Customizing

  • Pass classes to add or override utilities: they come last, so classes: 'w:full' wins over the default width.
  • Cells take any component: put a JxBadge or a JxButton in a row.

Responsive

  • On narrow screens the table scrolls sideways inside its frame, never the page. Cells do not wrap.

Accessibility

  • A real <table> with <caption> and <th scope="col">.
  • Sortable headers are buttons inside the <th>, which carries aria-sort="ascending" or "descending".
  • The sort arrow is decorative; the direction is exposed by aria-sort.

Limitations

  • Sorting, filtering and paging are yours: the table renders what you give it.
  • No row selection and no column resizing.
