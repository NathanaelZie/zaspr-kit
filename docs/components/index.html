Getting started

Components

jx_ui: accessible Jaspr components styled with JX classes, rendered here as-is.

Installation 

dart pub add jx_ui:^0.0.2

The components are plain JX classes, compiled into your own stylesheet. List the package in jx.yaml so the CLI or jx_builder reads them:

Note

Every demo on this page is the real component, rendered on the server with no JavaScript. The switch, checkboxes and radios work as they are.

Button 

JxButton([.text('Save')], onClick: save)
JxButton([.text('Saving')], loading: saving)       // spinner, disabled, aria-busy
JxButton([.text('Continue')], fullWidth: true)
JxButton([.text('Docs')], href: '/docs', variant: JxButtonVariant.outline)

With href, the button renders an <a>: links stay links for assistive technology.

Modal

Delete this project?

The project, its pages and its deployments are removed. This cannot be undone.

Invite a teammate

They get an email with a link to join this workspace.

The modal is a native <dialog>, opened and closed by HTML command buttons: no JavaScript, not even on this static page. The browser moves the focus inside, keeps it there, closes on Escape and returns the focus to the trigger. A click on the backdrop closes it too, unless dismissible: false. 

JxModalTrigger(target: 'delete', [.text('Delete project')])

JxModal(
  id: 'delete',
  title: 'Delete this project?',
  description: 'This cannot be undone.',
  size: JxModalSize.sm,
  actions: [
    JxButton([.text('Cancel')], variant: JxButtonVariant.ghost,
        attributes: JxModal.closeAttributes('delete')),
    JxButton([.text('Delete')], variant: JxButtonVariant.danger, onClick: delete),
  ],
  [],
)

Note

Command buttons are supported in current Chrome, Edge, Firefox and Safari. Closing on a backdrop click relies on closedby, not yet everywhere: Escape and the buttons always work. For older browsers, call showModal() from a client component.

Headers are <th scope="col">; the sorted one carries aria-sort. Numeric columns align right with tabular digits, rows are striped, and with stickyHeader the header stays visible while the table scrolls. On a narrow screen the table scrolls sideways inside its frame, never the page. 

JxDataTable(
  caption: 'Invoices',
  columns: const [
    JxColumn('Client', sortable: true),
    JxColumn('Amount', numeric: true, sortable: true),
  ],
  rows: [
    for (final i in invoices) [.text(i.client), .text(i.amount)],
  ],
  sortColumn: sortColumn,
  sortAscending: ascending,
  onSort: (column) => setState(() => sortColumn = column),
)

JxPagination(page: page, pageCount: 12, onChange: (p) => setState(() => page = p))
JxPagination(page: page, pageCount: 12, href: (p) => '/invoices?page=$p')  // plain links

Customizing

Every component takes a classes argument, appended after its own classes: JxButton(..., classes: 'w:full'). Colors come from the theme families blue, gray, red, green and yellow: redefine them in theme.extend.colors to restyle every component at once.
