Getting started

Components

jx_ui: accessible Jaspr components styled with JX classes, rendered here as-is.

Installation 

dart pub add jx_ui

The components are plain JX classes, compiled into your own stylesheet. List the package in jx.yaml so the CLI or jx_builder reads them:

Button 

JxButton([.text('Save')], onClick: save)
JxButton([.text('Delete')], variant: JxButtonVariant.danger)
JxButton([.text('Docs')], href: '/docs', variant: JxButtonVariant.outline)

With href, the button renders an <a>: links stay links for assistive technology.

Badge

Neutral Info Success Warning Danger 
const JxBadge('Beta', tone: JxTone.info)

Alert

Saved

Your changes are online.

Payment failed

Check the card number, then try again.

warning and danger alerts carry role="alert" and are read immediately; the others carry role="status".

Text field

As shown on your profile.

Enter a complete email address.

The label, the hint and the error are linked to the input with for, aria-describedby and aria-invalid. 

const JxTextField(
  id: 'email',
  label: 'Email',
  type: InputType.email,
  error: 'Enter a complete email address.',
)

Customizing

Every component takes a classes argument, appended after its own classes: JxButton(..., classes: 'w:full'). Colors come from the theme families blue, gray, red, green and yellow: redefine them in theme.extend.colors to restyle every component at once.
