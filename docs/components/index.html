JX Components

33 accessible Jaspr components, styled with JX classes and shipped in jx_cli. Every preview on these pages is the real component.

JX CSS and JX Components

JX CSS JX Components
What Utility classes compiled to CSS Ready-made Jaspr components
Import package:jx_cli/jx_cli.dart package:jx_cli/ui.dart
You write div(classes: 'p:4 bg:blue-700') JxButton([.text('Save')])
Styling Your classes JX classes inside, plus your `classes`

The components are built with JX CSS and nothing else: no stylesheet to import, no runtime. Their classes are compiled into your own jx.css with the rest of your site, so they follow your theme.
