New in 0.0.3

Released with jx_cli 0.0.3: Accordion, Drawer, Combobox, Toast, Tabs, Dropdown menu, Steps, Stat, Segmented control, Slider, Date field; dark tones for badges and alerts, required markers, errors on checkboxes and radio groups, indeterminate progress, linked tooltips that Escape hides, vertical tabs, a dropdown menu that closes on a click outside, the scheme: utility for native pickers in dark mode, the shared design tokens and the disabled state of link buttons.

Planned

Not started. Nothing on this list can be installed today.

Component Category Why it is not there yet
Date picker Forms A calendar grid with full keyboard support: needs its own client component.
Command palette Overlays Search across actions, on top of the combobox and the modal.
Popover menu Overlays The dropdown on the Popover API, once CSS anchor positioning is in every browser.
Custom listbox Forms A combobox with a styled list and active-option keyboard handling.

Known limitations

  • Tabs, and the Escape and click-outside handling of tooltips and menus, need to run in the browser (@client).
  • The dropdown menu is a disclosure, not an ARIA menu: no arrow keys between entries.
  • Date, time and suggestion pickers are the browser's own and cannot be styled.
  • Modals and drawers rely on command buttons and closedby, available in current browsers only.
