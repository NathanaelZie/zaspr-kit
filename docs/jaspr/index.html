Using with Jaspr

Writing classes in components, handling state and reusing styles.

The classes attribute

Every Jaspr HTML component accepts a classes string: that is where utilities live. 

button(
  classes: 'px:5 py:3 br:lg fw:semibold c:white bg:blue hover:bg:blue-700',
  onClick: save,
  [.text('Save')],
)

Conditional classes

Build a list and join it: each branch stays a string literal the CLI can read.

li(
  classes: [
    'px:3 py:2 br:md',
    if (active) 'c:white bg:blue' else 'c:gray-700 hover:bg:gray-100',
  ].join(' '),
  [.text(label)],
)

The engine at runtime

The jx_engine package can also be used as a library, on the server or in the browser. This site uses it to compile its examples and to power the playground: 

import 'package:jx_engine/jx_engine.dart';

final result = JxEngine().compile('p:4 md:p:8');
print(result.css);       // generated stylesheet
print(result.ruleCount); // number of rules
print(result.warnings);  // rejected classes
