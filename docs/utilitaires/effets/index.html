Effets et transitions

Opacité, ombres, transitions, translation, échelle, rotation et inclinaison.

opacity

o:
Classe Propriétés CSS
o: opacity
  • Tokens du thème : opacity
  • Valeurs arbitraires : oui, entre crochets
o:50 
.o\:50 {
  opacity: 0.5;
}

sh:
Classe Propriétés CSS

  • Tokens du thème : shadow
  • Valeurs arbitraires : oui, entre crochets

transition

tr:
Valeur Déclarations
tr:none transition-property: none
tr:all transition-property: all; transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1); transition-duration: 150ms
tr:colors transition-property: color, background-color, border-color, text-decoration-color, fill, stroke; transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1); transition-duration: 150ms
tr:opacity transition-property: opacity; transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1); transition-duration: 150ms
tr:shadow transition-property: box-shadow; transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1); transition-duration: 150ms
tr:transform transition-property: transform, translate, scale, rotate; transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1); transition-duration: 150ms
tr:filter transition-property: filter, backdrop-filter; transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1); transition-duration: 150ms
tr:default transition-property: color, background-color, border-color, opacity, box-shadow, transform, translate, scale, rotate, filter, backdrop-filter; transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1); transition-duration: 150ms
tr:none 
.tr\:none {
  transition-property: none;
}
tr:all 
.tr\:all {
  transition-property: all;
  transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1);
  transition-duration: 150ms;
}

translate-x

tx:
Classe Propriétés CSS
tx: --jx-tx
  • Tokens du thème : spacing
  • Mots-clés : full 1/2 auto
  • Valeurs arbitraires : oui, entre crochets
  • Valeurs négatives : oui
tx:full 
.tx\:full {
  --jx-tx: 100%;
  translate: var(--jx-tx, 0) var(--jx-ty, 0);
}

@property --jx-tx {
  syntax: "*";
  inherits: false;
}
tx:8 
.tx\:8 {
  --jx-tx: 2rem;
  translate: var(--jx-tx, 0) var(--jx-ty, 0);
}

@property --jx-tx {
  syntax: "*";
  inherits: false;
}
