Formulaires

Apparence native, curseur, redimensionnement, sélection et anneau de focus.

appearance

app:
Classe Propriétés CSS
app: -webkit-appearance, appearance
  • Mots-clés : none auto
  • Valeurs arbitraires : non
app:none 
.app\:none {
  -webkit-appearance: none;
  appearance: none;
}

Classe Propriétés CSS
