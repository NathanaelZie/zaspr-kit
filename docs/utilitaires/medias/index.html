Médias et fonds

Proportions, cadrage des images, position et répétition du fond, style de bordure.

aspect-ratio

ar:
Classe Propriétés CSS
ar: aspect-ratio
  • Mots-clés : auto square video photo portrait
  • Valeurs arbitraires : oui, entre crochets
ar:auto 
.ar\:auto {
  aspect-ratio: auto;
}

object-fit

obf:
Classe Propriétés CSS
obf: object-fit
  • Mots-clés : contain cover fill none scale-down
  • Valeurs arbitraires : non
obf:contain 
.obf\:contain {
  object-fit: contain;
}
