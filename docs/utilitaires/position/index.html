  • Mots-clés : static relative absolute fixed sticky
  • Valeurs arbitraires : non

}

z-index

z:
Classe Propriétés CSS
z: z-index
  • Mots-clés : 0 10 20 30 40 50 auto
  • Valeurs arbitraires : oui, entre crochets
  • Valeurs négatives : oui

  z-index: 0;
}
