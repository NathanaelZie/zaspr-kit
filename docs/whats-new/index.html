What's new

0.3 builds the stylesheet inside jaspr serve, adds components and converts Tailwind. 0.2 brought dark mode, groups, filters, gradients and animations.

Version 0.3

Package What it does
jx_builder jaspr serve and jaspr build generate jx.css. No second terminal.
jx_ui Button, card, badge, alert and text field, accessible and themable.
jx migrate Converts Tailwind classes in a project, with a report of approximations.
packages: jx.yaml key: scans the lib/ folder of component libraries.

Upgrading to 0.3

  • Raise every jx_* constraint to ^0.3.0. No class changes its output.
  • To use jx_builder, delete the web/jx.css written by the CLI first.

In 0.2

New variants

  • dark: follows the system preference, or a .dark class with dark_mode: class.
  • group-hover:, peer-checked: and the other group-* / peer-* variants react to the state of a parent or a sibling.
  • motion-safe:, motion-reduce:, print:, contrast-more:, portrait:, landscape:.
dark : bg : gray-900 
@media (prefers-color-scheme: dark) {
  .dark\:bg\:gray-900 {
    background-color: #111827;
  }
}
group-hover : c : blue 
.group:hover .group-hover\:c\:blue {
  color: #3b82f6;
}
motion-reduce : anim : none 
@media (prefers-reduced-motion: reduce) {
  .motion-reduce\:anim\:none {
    animation: none;
  }
}

Messages and diagnostics

A misspelled class is reported with a fix, offered only when that fix compiles. An unknown value lists the accepted values. 

Warning: Invalid class syntax: "hover:hover:c:red" (repeated variant "hover").
Warning: Unknown class "pd:4": did you mean "p:4"?
Warning: "c:bleu" ignored: Invalid value "bleu" for "c". Did you mean "c:blue"?; accepted values: transparent, current, black, white, gray, gray-100, gray-300, gray-500, gray-700, gray-900, red, red-100…; or an arbitrary value in brackets.

In Dart, JxParser.analyze returns the reason for a rejection as a code: unsafeValue, duplicateVariant, invalidValue…

Security

Bracketed values are validated before being written to the stylesheet. The details are on the Security page.

Migrating from 0.1

  • A plain value can no longer start with a dot: lh:.5 is rejected, write lh:[.5].
  • In an arbitrary value, ;, {, }, <, ! and \ are rejected.
  • The _ inside url(…) are no longer turned into spaces. For a literal _ elsewhere, write \_.
  • tx: and ty: now produce a --jx-tx / --jx-ty variable: the rendering is the same, the generated CSS changes.
