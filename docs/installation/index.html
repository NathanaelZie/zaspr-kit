Getting started

Installation

Add the CLI to a Jaspr project, generate the configuration and link the stylesheet.

Requirements

  • Dart 3.10 or newer.
  • A Jaspr 0.22 project or newer (the generated CSS also works with plain HTML).

Add the dependency

Add jx_cli as a dev dependency from pub.dev:

$ dart pub add dev:jx_cli

This adds to your file:

Global install

To use jx outside a project, install it as a global command with dart pub global activate jx_cli, then simply run jx build.

Create the configuration

jx init creates a commented jx.yaml file at the root of the project:

$ dart run jx_cli:jx init

At least adjust output so the stylesheet is written to a folder served by Jaspr, for example web/jx.css. Every option is described on the Configuration page.

Build

Run a single build, or let the CLI watch your sources during development:

$ dart run jx_cli:jx build
$ dart run jx_cli:jx build -w

Note

For production, add -m to minify the CSS. The preflight (reset stylesheet) is included by default.
