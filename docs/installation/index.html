Installation

Ajoutez la CLI à un projet Jaspr, générez la configuration et liez la feuille produite.

Prérequis

  • Dart 3.10 ou plus récent.
  • Un projet Jaspr 0.22 ou plus récent (le CSS produit fonctionne aussi avec du HTML classique).

Ajouter la dépendance

Ajoutez jx_cli en dépendance de développement depuis pub.dev :

$ dart pub add dev:jx_cli

Ce qui ajoute à votre fichier :

Installation globale

Pour utiliser jx en dehors d'un projet, installez-la en commande globale avec dart pub global activate jx_cli, puis lancez simplement jx build.

Créer la configuration

La commande jx init crée un fichier jx.yaml commenté à la racine du projet :

$ dart run jx_cli:jx init

Adaptez au minimum output pour écrire la feuille dans un dossier servi par Jaspr, par exemple web/jx.css. Toutes les options sont décrites dans la page Configuration.

Compiler

Lancez une compilation unique, ou laissez la CLI surveiller vos sources pendant le développement :

$ dart run jx_cli:jx build
$ dart run jx_cli:jx build -w

À savoir

Pour la production, ajoutez -m : le CSS est minifié. Le preflight (feuille de réinitialisation) est inclus par défaut.
