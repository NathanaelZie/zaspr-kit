# jx_builder

[build_runner](https://pub.dev/packages/build_runner) integration for **JX CSS** (ZASPR Kit), the utility-first CSS framework written in Dart and built for Jaspr.

With `jx_builder` in your dev dependencies, `jaspr serve` and `jaspr build` generate `web/jx.css` by themselves. There is no `jx build` step to run or to forget, and the stylesheet is rebuilt every time you save a file.

## Installation

```bash
dart pub add dev:jx_builder
```

Link the stylesheet in your `Document`:

```dart
Document(
  head: [link(rel: 'stylesheet', href: '/jx.css')],
  body: App(),
)
```

Then run Jaspr as usual:

```bash
jaspr serve
```

## Configuration

The builder reads `jx.yaml` like the CLI does: `content`, `extensions`, `exclude`, `packages`, `minify`, `reset`, `dark_mode` and `theme`. The `output` key is ignored: the stylesheet is always served at `/jx.css`.

```yaml
# jx.yaml
content: [lib]
extensions: [dart]
dark_mode: media
theme:
  extend:
    colors:
      brand: '#3B6CF0'
```

`jx.yaml` is read when the build starts. To have changes picked up while `jaspr serve` is running, add it to the build sources:

```yaml
# build.yaml
targets:
  $default:
    sources:
      include:
        - $package$
        - lib/**
        - web/**
        - jx.yaml
        - pubspec.yaml
```

To minify only in release builds (`jaspr build`):

```yaml
# build.yaml
targets:
  $default:
    builders:
      jx_builder:jx_css:
        release_options:
          minify: true
```

## Migrating from `jx build`

The CSS is now a generated build asset, so delete the `web/jx.css` written by the CLI (build_runner refuses to overwrite a source file), and remove `jx build` from your scripts.

## The JX CSS family

| Package | Role |
| :--- | :--- |
| [`jx_cli`](https://pub.dev/packages/jx_cli) | Command line: `jx init`, `jx build`, `jx migrate`. |
| [`jx_builder`](https://pub.dev/packages/jx_builder) | build_runner integration: CSS generated by `jaspr serve` and `jaspr build`. |
| [`jx_ui`](https://pub.dev/packages/jx_ui) | Ready-made Jaspr components styled with JX. |
| [`jx_engine`](https://pub.dev/packages/jx_engine) | Compilation engine and Tailwind converter, usable as a library. |
| [`jx_rules`](https://pub.dev/packages/jx_rules) | Utility catalog and rule registry. |
| [`jx_theme`](https://pub.dev/packages/jx_theme) | Design tokens and default theme. |
| [`jx_parser`](https://pub.dev/packages/jx_parser) | Class syntax parser. |
| [`jx_generator`](https://pub.dev/packages/jx_generator) | CSS serialization and preflight. |
| [`jx_core`](https://pub.dev/packages/jx_core) | Shared models, contracts and exceptions. |

Documentation: https://nathanaelzie.github.io/zaspr-kit/
