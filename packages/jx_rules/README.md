# jx_rules

Package de définition et de registre des règles CSS pour le framework **JX CSS**.

## Responsabilités

- Classe de base extensible pour les règles utilitaires (`JxRule`).
- Registre central des règles utilitaires (`JxRuleRegistry`).
- Mécanisme d'échappement CSS et liaison avec les modèles de `jx_core` et `jx_theme`.

## Dépendances

- `jx_core` (interne)
- `jx_theme` (interne)
