## 0.0.2

- New form components: `JxTextArea`, `JxSelect`, `JxCheckbox`, `JxSwitch` (CSS-only, `role="switch"`) and `JxRadioGroup`.
- New feedback components: `JxSpinner`, `JxProgress`, `JxSkeleton` and `JxEmptyState`.
- New overlay components: `JxModal` (native `<dialog>`, opened and closed with command buttons, no JavaScript) and `JxModalTrigger`.
- New data components: `JxDataTable` (caption, sortable headers with `aria-sort`, numeric columns, striped rows, sticky header, empty state) and `JxPagination`.
- New display components: `JxAvatar`, `JxTooltip`, `JxKbd`, `JxBreadcrumbs` and `JxDivider`.
- `JxButton`: `loading` (spinner, disabled, `aria-busy`) and `fullWidth`.
- `JxCard`: `description` and `footer`.
- `JxBadge` no longer stretches in a column layout.

## 0.0.1

First release: `JxButton`, `JxCard`, `JxBadge`, `JxAlert` and `JxTextField`, with light and dark styles, visible keyboard focus and ARIA wiring.
