# Code de conduite

[English version](CODE_OF_CONDUCT.md)

ZASPR Kit se veut un projet accueillant pour tout le monde, quels que soient l'expérience, l'origine ou l'identité de chacun.

## Comportements attendus

- Être respectueux et patient, en particulier avec les nouveaux venus.
- Discuter des idées et du code, pas des personnes.
- Donner et accepter des critiques constructives.
- Supposer la bonne foi, et demander avant de conclure.

## Comportements inacceptables

- Insultes, harcèlement, menaces ou propos discriminatoires.
- Langage ou images à caractère sexuel.
- Publier des informations privées sur quelqu'un sans son accord.
- Messages hors sujet ou perturbateurs répétés.

## Portée

Ce code s'applique à tous les espaces du projet : issues, pull requests, discussions et relectures, ainsi qu'à toute personne qui représente le projet ailleurs.

## Signalement

Signalez un problème au mainteneur, Nathanael ZIE ([@NathanaelZie](https://github.com/NathanaelZie)), ou utilisez la fonction « Report content » de GitHub sur le message concerné. Les signalements sont traités de façon confidentielle.

## Application

Le mainteneur peut modifier ou retirer des contributions, et avertir, exclure temporairement ou définitivement toute personne dont le comportement va à l'encontre de ce code.
