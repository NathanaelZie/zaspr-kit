# Getting help

*[Version française](SUPPORT.fr.md)*

ZASPR Kit is maintained in the open. Ask in public whenever you can: the answer then helps the next person with the same question.

## Where to go

| You want to… | Go to |
|---|---|
| Learn how something works | The [documentation](https://nathanaelzie.github.io/zaspr-kit/docs/introduction/) and the [playground](https://nathanaelzie.github.io/zaspr-kit/playground/) |
| Ask how to do something | [Discussions, Q&A](https://github.com/NathanaelZie/zaspr-kit/discussions/categories/q-a) |
| Share an idea or show what you built | [Discussions](https://github.com/NathanaelZie/zaspr-kit/discussions) |
| Report a bug | A [new issue](https://github.com/NathanaelZie/zaspr-kit/issues/new/choose), using the bug template |
| Ask for a utility, a variant or a component | A [new issue](https://github.com/NathanaelZie/zaspr-kit/issues/new/choose), using the feature template |
| Report a vulnerability | Privately, as described in [SECURITY.md](SECURITY.md). Never in a public issue |

## Ask a good question

- Give your versions of jx_cli (`dart run jx_cli:jx --version`), Dart and Jaspr.
- Show the classes, the `jx.yaml` section or the command, and the CSS or the message you got.
- Keep the example small: a few classes are easier to check than a whole project.

## What to expect

ZASPR Kit is maintained on personal time. Questions and issues are read regularly, but there is no guaranteed response time. Everyone who takes part follows the [code of conduct](CODE_OF_CONDUCT.md).
