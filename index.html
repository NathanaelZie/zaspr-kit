Construisez vos interfaces Jaspr avec du CSS utilitaire

ZASPR Kit compile des classes comme md:hover:bg:blue en CSS, directement à partir de vos composants Jaspr. Un parseur, un thème et une CLI, entièrement en Dart.

$ dart run jx_cli:jx build
Lire la documentation

Version actuelle : v0.1.0. Dart 3.10 et Jaspr 0.22 minimum.

Anatomie d'une classe

md : hover : bg : blue !

Variantes

md: hover:

Breakpoints et états, cumulables. Les pseudo-éléments se placent toujours en fin de sélecteur.

Identifiant

bg

La propriété, en abrégé : bg, p, fs, cols, ring…

Valeur

blue

Un token du thème, un mot-clé ou une valeur arbitraire entre crochets.

Importance

!

Facultatif : ajoute !important à la déclaration.

CSS produit par le moteur

@media (min-width: 768px) {
  .md\:hover\:bg\:blue\!:hover {
    background-color: #3b82f6 !important;
  }
}

Démarrez en trois étapes

Ajoutez la CLI, générez la configuration, lancez la compilation. La feuille produite ne contient que les classes présentes dans vos sources.

Lire le guide d'installation
  1. 1

    Ajouter la dépendance

    $ dart pub add dev:jx_cli
  2. 2

    Créer la configuration

    $ dart run jx_cli:jx init
  3. 3

    Compiler en continu

    $ dart run jx_cli:jx build -w

Une syntaxe lisible et prévisible

Variantes, identifiant, valeur et importance : chaque classe se lit de gauche à droite. Le CSS ci-dessous est compilé par le moteur au rendu de cette page.

Découvrir la syntaxe
p:4 
.p\:4 {
  padding: 1rem;
}
md : cols : 3 
@media (min-width: 768px) {
  .md\:cols\:3 {
    grid-template-columns: repeat(3, minmax(0, 1fr));
  }
}
hover : bg : blue-700 
.hover\:bg\:blue-700:hover {
  background-color: #1d4ed8;
}
w : [calc(100%_-_2rem)] 
.w\:\[calc\(100\%_-_2rem\)\] {
  width: calc(100% - 2rem);
}
focus-visible : ring : 2 
.focus-visible\:ring\:2:focus-visible {
  box-shadow: 0 0 0 2px var(--jx-ring-color, currentColor);
}

Un thème, vos tokens

Couleurs, espacements, typographie et breakpoints sont des tokens. Étendez-les dans jx.yaml sans rien redéfinir, ou remplacez une catégorie entière.
