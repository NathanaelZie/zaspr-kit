A complete utility-first styling ecosystem for Jaspr. Write expressive classes, build accessible components, and ship faster, powered entirely by Dart.

Anatomy of a class

md : hover : bg : blue !

Variants

md: hover:

Breakpoints and states, stackable. Pseudo-elements always go at the end of the selector.

Utility

bg

The property, abbreviated: bg, p, fs, cols, ring…

Value

blue

A theme token, a keyword or an arbitrary value in brackets.

Important

!

Optional: adds !important to the declaration.

Three parts, one package

jx_cli brings the classes, the tools that compile them and the components built with them. Use the classes alone, or the components on top.

JX CSS

Utility classes with a readable syntax: variants, utility, value, importance. 113 rules in 15 families, on a theme you extend.

div(classes: 'flex gap:4 p:6 md:p:8') Class syntax

JX Engine and CLI

The compiler, a watch mode, a build_runner builder and a Tailwind migration. Only the classes found in your sources reach the stylesheet.

dart run jx_cli:jx build -w Command line

33 accessible components: buttons, fields, dialogs, drawers, accordions, data tables. Styled with JX, themed by your tokens.

A readable, predictable syntax

Variants, utility, value and importance: every class reads from left to right. The CSS below is compiled by the engine when this page is rendered.

Get started in three steps

Add the CLI, generate the configuration, start the build. The stylesheet only contains the classes found in your sources.

Read the installation guide
  1. 1

    Add the dependency

    $ dart pub add jx_cli
  2. 2

    Create the configuration

    $ dart run jx_cli:jx init
  3. 3

    Build in watch mode

    $ dart run jx_cli:jx build -w

What changes in your workflow

Styling stays in your components and in Dart. Here is what JX takes off your plate.

Without JX With ZASPR Kit
Toolchain A separate toolchain to install and keep up to date next to the Dart SDK. One dev dependency: dart pub add jx_cli. The compiler is Dart.
Stylesheet size Hand-written or framework CSS tends to grow with every page. Only the classes found in your sources are compiled.
Typos A misspelled class silently does nothing. The build warns about unknown classes and suggests the closest one.
Rebuilds A second terminal running a watcher. jx build -w, or the builder inside jaspr serve.
Components Build and style each control, then add the ARIA wiring. Accessible components, styled with the same classes and theme.
Migration Rewrite every class by hand. jx migrate converts Tailwind classes and reports approximations.
