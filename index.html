Z New: automatic builds, components and Tailwind migration

Style your Jaspr apps with utility-first CSS

ZASPR Kit compiles classes like md:hover:bg:blue into CSS, straight from your Jaspr components. A parser, a theme and a CLI, all in Dart. No Node.js required.

$ dart run jx_cli:jx build
Read the docs

Current version: v0.3.0. Requires Dart 3.10 and Jaspr 0.22.

Anatomy of a class

md : hover : bg : blue !

Variants

md: hover:

Breakpoints and states, stackable. Pseudo-elements always go at the end of the selector.

Utility

bg

The property, abbreviated: bg, p, fs, cols, ring…

Value

blue

A theme token, a keyword or an arbitrary value in brackets.

Important

!

Optional: adds !important to the declaration.

CSS produced by the engine

@media (min-width: 768px) {
  .md\:hover\:bg\:blue\!:hover {
    background-color: #3b82f6 !important;
  }
}

Get started in three steps

Add the CLI, generate the configuration, start the build. The stylesheet only contains the classes found in your sources.

Read the installation guide
  1. 1

    Add the dependency

    $ dart pub add dev:jx_cli
  2. 2

    Create the configuration

    $ dart run jx_cli:jx init
  3. 3

    Build in watch mode

    $ dart run jx_cli:jx build -w

A readable, predictable syntax

Variants, utility, value and importance: every class reads from left to right. The CSS below is compiled by the engine when this page is rendered.

Learn the syntax
p:4 
.p\:4 {
  padding: 1rem;
}
md : cols : 3 
@media (min-width: 768px) {
  .md\:cols\:3 {
    grid-template-columns: repeat(3, minmax(0, 1fr));
  }
}
hover : bg : blue-700 
.hover\:bg\:blue-700:hover {
  background-color: #1d4ed8;
}
w : [calc(100%_-_2rem)] 
.w\:\[calc\(100\%_-_2rem\)\] {
  width: calc(100% - 2rem);
}
focus-visible : ring : 2 
.focus-visible\:ring\:2:focus-visible {
  box-shadow: 0 0 0 2px var(--jx-ring-color, currentColor);
}
